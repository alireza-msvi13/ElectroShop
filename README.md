# 🛒 ElectroShop | E-commerce Platform

A responsive e-commerce frontend built with Next.js and TypeScript, featuring product browsing, user authentication, shopping cart, wishlist, and separate admin and user dashboards.

## 🚀 Some Features

- **Authentication:** User registration, login, and JWT-based authentication.
- **Product Catalog:** Product listing, category browsing, product details, and related products.
- **Shopping Cart:** Cart management with Redux and local storage persistence.
- **Wishlist:** Add and remove favorite products.
- **User Dashboard:** Profile management and wishlist access.
- **Admin Dashboard:** Product, category, user, and contact message management with analytics overview.
- **Contact:** Contact form and interactive map.
- **UI:** Responsive design with Persian RTL support.

## 🛠️ Tech Stack

- Next.js 14 & React 18
- TypeScript
- Redux Toolkit & RTK Query
- Tailwind CSS
- Formik & Yup
- Leaflet & React Leaflet
- Recharts & Swiper
